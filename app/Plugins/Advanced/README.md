# Advanced

Plugin complementar para documentacao OpenAPI/Swagger e hardening leve da borda HTTP.

Responsabilidades:

- concentrar configuracao e geracao do contrato OpenAPI publicado
- expor utilitarios de Swagger UI para desenvolvimento e homologacao
- aplicar headers de seguranca simples sem espalhar regras pelo adapter HTTP
