# Data Seeds

Seeds basicas para desenvolvimento e testes do plugin de dados.

Responsabilidades:

- popular contas e registros minimos para ambiente local
- popular cenarios canonicos do case de saque PIX para validacao manual e smoke local
- permitir cenarios repetiveis de validacao em Docker
- rastrear seeds de bootstrap de execucao unica em `seed_execution`
- manter massa de teste simples e previsivel
