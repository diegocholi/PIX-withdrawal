# Submission Package

## Objetivo

Consolidar os artefatos que devem compor a entrega técnica final do case.

## Artefatos obrigatórios

- código fonte do módulo `PIX-withdrawal`
- `README.md` principal
- documentação em `docs/`
- `docker-compose.yml`
- `.env.example`

## Pacote mínimo esperado

- setup reproduzível apenas com Docker Compose
- documentação suficiente para subir, operar e validar a solução
- contratos HTTP navegáveis por OpenAPI e Swagger UI
- massa canônica de dados para demonstração do case

## Conferência final

- a raiz do módulo contém o `README.md`
- a pasta `docs/` possui índice e documentos especializados
- nenhum passo essencial depende de conhecimento externo ao repositório
- comandos citados na documentação foram pensados para execução em container
